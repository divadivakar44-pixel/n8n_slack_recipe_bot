
# n8n Slack Recipe Bot

## Project Overview
An AI-powered Slack automation built using n8n.

Users enter a recipe name in Slack, and the AI generates the required ingredients and quantities.

## Technologies
- n8n
- Slack API
- OpenAI
- Basic LLM Chain
- Code Node

## Workflow
1. Slack Trigger
2. Edit Fields
3. IF Validation
4. Basic LLM Chain
5. OpenAI Chat Model
6. Code Node
7. Slack Send Message

## Expected Output
The bot responds in the same Slack channel with a formatted ingredient list.

## Setup
1. Import workflow JSON into n8n.
2. Configure Slack credentials.
3. Configure OpenAI credentials.
4. Test and activate workflow.

## Security
API keys and credentials must remain inside n8n.
